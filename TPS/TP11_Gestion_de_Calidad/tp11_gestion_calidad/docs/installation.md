# Installation

## Stable release

To install TP11_Gestion_de_Calidad, run this command in your terminal:

```sh
uv add tp11_gestion_calidad
```

Or if you prefer to use `pip`:

```sh
pip install tp11_gestion_calidad
```

## From source

The source files for TP11_Gestion_de_Calidad can be downloaded from the [Github repo](https://github.com/Chate19/tp11_gestion_calidad).

You can either clone the public repository:

```sh
git clone https://github.com/Chate19/tp11_gestion_calidad
```

Or download the [tarball](https://github.com/Chate19/tp11_gestion_calidad/tarball/main):

```sh
curl -OJL https://github.com/Chate19/tp11_gestion_calidad/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd tp11_gestion_calidad
uv sync
```
